# Fake News Detection Using Machine Learning

## Project Overview
Fake News Detection is a machine learning project that aims to classify news articles as **Real or Fake** based on their textual content.

The project uses Natural Language Processing (NLP) techniques and machine learning to analyse news text and identify potentially misleading information.

## Objectives
- Understand and preprocess textual news data.
- Apply NLP techniques to prepare text for model training.
- Build a machine learning model to classify news articles.
- Predict whether a news article is Real or Fake.

## Technologies Used
- Python
- Machine Learning
- Natural Language Processing (NLP)
- Pandas
- NumPy
- Scikit-learn

## Project Workflow
1. Dataset collection and preparation.
2. Data cleaning and text preprocessing.
3. Text feature extraction.
4. Machine learning model training.
5. Model evaluation and news classification.

## Project Files

| File | Description |
|---|---|
| `downloading_dataset.ipynb` | Dataset downloading and preparation |
| `fake_news_detector.ipynb` | Main notebook for model development |
| `final_dataset.csv` | Dataset used in the project |
| `model.pkl` | Saved trained machine learning model |

## Project Outcome
The project demonstrates how machine learning and NLP techniques can be applied to text classification problems, particularly in identifying fake and real news articles.
